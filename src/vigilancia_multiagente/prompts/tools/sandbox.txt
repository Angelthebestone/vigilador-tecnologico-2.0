<rules>
  <rule>The sandbox has NO network access — do not attempt to download data or call APIs from within executed code.</rule>
  <rule>Always import libraries inside the code string (the environment does not auto-import).</rule>
  <rule>To analyze collected data (publication counts per year, confidence distributions, term frequencies, trend slopes), pass it as JSON and process it with pandas/numpy/scipy in the code.</rule>
  <rule>Audit logging is automatic — every execution is recorded with timestamp and result summary.</rule>
  <rule>EVERY chart you generate MUST be returned as a base64 PNG so it can be embedded in the final report. After savefig, read the file and emit it.</rule>
  <rule>EVERY chart MUST be accompanied by a 1-2 sentence textual explanation of what it shows and why it matters — never emit a chart without interpretation.</rule>
</rules>
